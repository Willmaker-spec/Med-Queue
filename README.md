# Med-Queue

A frontend-based virtual queue management platform that helps patients find clinics, join queues remotely, and track their waiting status in real time.

## Features

- Find and browse clinics
- View department queues
- Join a virtual queue
- Receive a digital queue number
- Track queue position
- View estimated waiting time
- Patient dashboard
- Clinic staff dashboard
- Waiting-room display

## Run locally

Install dependencies and start the Vite development server from the repository root:

```sh
npm install
npm run dev
```

The app screens are available at `/`, `/clinics`, `/clinics/:id`, `/queue`,
`/patient-dashboard`, and `/staff-dashboard`.
